MESSI 1000 — REACT FRONTEND PACKAGE (V2)

PACKAGE CONTENTS
- frontend/src/App.tsx       Main dashboard UI
- frontend/src/App.css       Dashboard styling and responsive layout
- frontend/src/index.css     Global styling and typography
- frontend/src/api.ts        Typed client for the FastAPI endpoints
- frontend/src/vite-env.d.ts Vite environment types
- frontend/vite.config.ts    Vite server plus /api proxy to FastAPI
- frontend/.env.example      Optional environment configuration

IMPORTANT
This is an overlay for the Vite React + TypeScript project already created in Codespaces.
It intentionally does not include package.json, package-lock.json, or node_modules.
It does not replace or modify the Python backend.

INSTALL IN CODESPACES
1. Upload this ZIP to the ROOT of the GitHub repository on branch feature/react-dashboard.
2. In Codespaces, switch to and pull that branch:
   git switch feature/react-dashboard
   git pull origin feature/react-dashboard
3. From the repository ROOT, extract the ZIP:
   unzip -o messi1000-react-frontend-v2.zip -d .
4. Start the backend in a separate terminal:
   cd /workspaces/messi-1000-the-road-to-1000
   python -m uvicorn api:app --host 0.0.0.0 --port 8000
5. Start the frontend in another terminal:
   cd /workspaces/messi-1000-the-road-to-1000/frontend
   npm run dev -- --host 0.0.0.0
6. Open forwarded port 5173. Vite proxies /api requests to the backend at 127.0.0.1:8000.
7. Verify the production build:
   cd /workspaces/messi-1000-the-road-to-1000/frontend
   npm run build

DEPENDENCIES
The project scaffold and recharts/lucide-react packages were installed during setup.
If they are missing, run:
   cd frontend && npm install recharts lucide-react

API CONNECTION
During Codespaces development, the browser calls the frontend's same-origin /api path and Vite proxies it to FastAPI. This avoids requiring permissive CORS settings for the forwarded browser ports.
For a separately deployed frontend, set VITE_API_BASE_URL to the deployed FastAPI origin and configure MESSI1000_CORS_ORIGINS on the backend to allow that exact frontend origin.

DATA INTEGRITY
- The default starting total of 943 remains labelled UNVERIFIED.
- The historical match archive is currently empty; the UI reports this instead of inventing records.
- Forecast outputs are from the existing configurable Monte Carlo/Poisson baseline, not a trained ML model.
- Fixture rows are loaded from the FastAPI endpoint and retain the backend's source coverage metadata.
