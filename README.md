# 🐐 Messi 1000: The Road to 1,000

### A probabilistic forecast of Lionel Messi's 1,000th official senior career goal

**Author:** [P Anjith Krishna](https://github.com/AnjithKrishna7)

## Overview

How soon could Lionel Messi reach 1,000 official senior career goals?

This project explores that question with a reproducible **Monte Carlo simulation**. It combines a manually maintained fixture calendar with assumptions about Messi's probability of appearing and his goals per appearance. Thousands of possible futures are simulated to estimate a milestone window and the probability of reaching the target by selected dates.

The project includes an interactive Streamlit dashboard, a CSV fixture dataset, a reusable Python simulation module, and automated tests.

> **Important:** This is a probabilistic simulation, not a trained machine-learning model. Its output depends heavily on the starting goal total, fixture coverage, and assumptions selected by the user. It should be treated as an educational forecasting experiment, not a factual prediction.

## Features

- Interactive controls for current goals, target, appearance probability, scoring rate, fixture cadence, simulation count, and forecast horizon.
- Monte Carlo simulation with a reproducible random seed.
- Separate labels for confirmed fixtures and synthetic future fixture slots.
- Median milestone date and a central 80% date interval among simulations that reach the target.
- Probability of reaching the target by year-end.
- Input validation and automated unit tests.

## How the model works

For every fixture row in the calendar, each simulation:

1. Samples whether Messi appears in that fixture using the configured appearance probability.
2. If he appears, samples the number of goals from a Poisson distribution with the configured mean goals per appearance.
3. Adds the sampled goals to that simulation's running career total.
4. Records the first fixture date on which the target is reached.

This process is repeated thousands of times. The model then summarizes the distribution of milestone dates.

### Model assumptions and limitations

The current baseline assumes:

- The same appearance probability for every fixture.
- The same goals-per-appearance rate for every appearance.
- Independent appearance and scoring outcomes between fixtures.
- A Poisson distribution for goals scored in an appearance.

It does **not** currently model minutes played, age-related decline, injuries, opponent strength, competition strength, penalties, tactical role, international breaks, retirement, or team qualification. The model also does not learn parameters from a historical match-by-match dataset.

The future fixture cadence is synthetic. It is not an official schedule and must never be presented as one. Replace projected slots with published fixtures as reliable schedules become available.

## Data notes

The fixture file is `data/fixtures.csv`. Each row contains a date, teams, competition, status, source URL, and notes.

- Rows marked `confirmed` are intended to represent published fixtures included in the dataset.
- Rows generated by the app are marked `Projected` and use generic opponents. They are assumptions, not announced matches.
- `data/fixture_windows.csv` stores conditional playoff windows separately. These are not guaranteed Messi appearances or confirmed team fixtures.

The default starting total in the dashboard is an editable historical snapshot. Career-goal totals can differ across trackers because of update timing and counting conventions. Verify the number against a consistent official-senior-match definition before running or publishing a forecast. Do not treat the default as live data.

## Run locally

### Requirements

- Python 3.10 or newer
- pip

### Setup

```bash
git clone https://github.com/AnjithKrishna7/messi-1000-the-road-to-1000.git
cd messi-1000-the-road-to-1000

python -m venv .venv
```

Activate the virtual environment:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux / Termux**
```bash
source .venv/bin/activate
```

Install dependencies and launch the dashboard:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Streamlit will print a local URL. Open it in your browser.

## Run tests

```bash
python -m pytest -q
```

The tests cover fixture loading, projected calendar generation, a deterministic milestone case, and invalid parameter handling.

## Updating the project

1. Verify Messi's current official senior career-goal total using a consistent source and counting rule.
2. Update the starting total in the dashboard's sidebar default if you want to change the initial value. The user can also edit it at runtime.
3. Add only officially published fixtures to `data/fixtures.csv`.
4. Keep conditional matches and playoff windows separate until participation and dates are confirmed.
5. Run the test suite.
6. Re-run the dashboard and clearly state the data cut-off date and assumptions whenever sharing results.

## Sources and further reading

Use primary sources for schedules and verify player statistics against a consistent match-level record. Useful starting points:
